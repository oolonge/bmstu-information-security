# Лабораторная работа 8-9: Электронная подпись RSA

## Описание
Консольная программа для создания и проверки электронной подписи файлов на основе алгоритма RSA.

## Структура
- `rsa.cpp/h` - реализация RSA (генерация ключей, подпись, проверка)
- `console_interface.cpp/h` - UI с 6 пунктами меню
- `exceptions.h` - обработка ошибок
- `main.cpp` - точка входа

## Алгоритм
- Генерация простых чисел (10000-50000)
- Вычисление ключей (n=p×q, e=65537, d=обратное к e)
- Подпись = шифрование хэша (DJB2) приватным ключом
- Формат: `[4 байта размер][8 байт подпись][данные]`

## Сборка и запуск
```bash
make
./rsa_signature
```

## Меню
1. Сгенерировать пару ключей
2. Загрузить ключи (.pub, .priv)
3. Сохранить ключи
4. Создать подпись (.signed)
5. Проверить подпись
6. Показать ключи

Все файлы в директории `out/`.
