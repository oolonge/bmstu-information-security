# AES-256 Cipher - Лабораторная работа

## Описание
Программа реализует алгоритм симметричного шифрования AES-256 для шифрования и расшифровки произвольных файлов (текстовых, архивов и др.).

## Структура проекта:
- `main.cpp` - точка входа программы
- `aes.h/cpp` - реализация алгоритма AES-256
- `aes_tables.h` - таблицы S-Box, Inv S-Box и константы Rcon
- `console_interface.h/cpp` - консольный интерфейс
- `exceptions.h` - обработка исключений
- `out/` - директория для входных/выходных файлов

## Особенности реализации:
- **AES-256**: использует 256-битный (32-байтный) ключ
- **Режим ECB**: простое блочное шифрование
- **Размер блока**: 128 бит (16 байт)
- **Padding**: Zero padding для последнего блока
- **Поддержка**: текстовые файлы, архивы, пустые файлы, однобайтовые файлы

## Пример использования:

### 1. Создание тестовых файлов:
```bash
# Создаем пустой файл
touch out/empty.txt

# Создаем файл с одним символом
echo "X" > out/single.txt

# Создаем текстовый файл
echo "Это тестовое сообщение для шифрования AES-256" > out/test.txt

# Создаем архив
zip out/archive.zip out/test.txt
```

### 2. Работа с программой:
```
=== AES-256 Шифрование ===
1. Сгенерировать ключ
2. Загрузить ключ из файла
3. Сохранить ключ в файл
4. Зашифровать файл
5. Расшифровать файл
6. Показать ключ
0. Выход
```

### Типичный сценарий:
1. Выберите пункт 1 - сгенерировать ключ
2. Выберите пункт 3 - сохранить ключ в файл (например, `mykey`)
3. Выберите пункт 4 - зашифровать файл (выберите из списка)
4. Выберите пункт 5 - расшифровать файл (выберите зашифрованный)
5. Выберите пункт 6 - показать текущий ключ

## Формат зашифрованного файла:
- Первые 8 байт: оригинальный размер файла (uint64_t)
- Далее: зашифрованные блоки по 16 байт
- Расширение: `.aes`
